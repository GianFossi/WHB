# Golden reference data

Generated by `tools/generate_golden.py` from CoolProp, Cantera and iapws, then
frozen. None of those packages is a build or test dependency.

Regenerate only when the reference itself should change. A regenerated file that
alters existing values silently weakens every test that reads it, so review the
diff rather than committing it blind.

See `docs/LIMITATIONS.md` §3.1: CoolProp returned a thermal conductivity two
orders of magnitude low for ammonia at 1000 K without raising an error. The
generator now screens reference points; the oracle is not truth.
