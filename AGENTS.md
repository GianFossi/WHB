# AGENTS.md

Entry point for AI coding assistants. This file exists at the repository
root because tools discover it here; it carries no rules of its own.

All AI instructions for this repository live in [`.ai/`](./.ai/):

| File | Read it for |
|---|---|
| [`.ai/AGENTS.md`](./.ai/AGENTS.md) | **canonical**: project conventions, build/test/run, repository layout, modification rules, Modification Memory Log |
| [`.ai/AI_STARTER_INSTRUCTIONS.md`](./.ai/AI_STARTER_INSTRUCTIONS.md) | WHB project profile: stack, module map, declared exceptions |
| [`.ai/AI_ENGINEERING_PROJECT_STANDARD.md`](./.ai/AI_ENGINEERING_PROJECT_STANDARD.md) | project-independent rules, cited by stable id (`PRIN-3`, `PERS-2`, ...) |

Read `.ai/AGENTS.md` before making any change, and follow it as
authoritative. Do not copy rule text back into this file.
