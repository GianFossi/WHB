## Demo Cases

This folder collects curated study inputs that would otherwise clutter the repository root.

- `cases/caso_design.json`: baseline greenfield design study with `H=6 m`, `L=6..10 m`, `Shell.ID <= 2300 mm`.
- `cases/caso_design_vincolato.json`: constrained variant of the same study.
- `cases/caso_design_vincolato_v2.json`: constrained study focused on `DNBR`, `FIV`, and `T_gas_out`.
- `cases/caso_design_vincolato_v3.json`: constrained study with coupled tube `OD/pitch` options plus `DNBR`, `FIV`, and `T_gas_out`.
- `cases/caso_verifica_finale.json`: rating/check case for the selected final design.
