# Input Schema And Options

The CLI reads JSON files generated by:

```bash
dotnet run --project src/Whb.Cli -- --template caso.json
```

The schema is intentionally simple and close to engineering datasheet language.
This document summarizes the most important fields; the generated template is
the practical starting point.

## Pressure Basis

- Fields ending in `_bara` are absolute pressures in bar.
- Pressure drops in `mbar`, `bar`, or `Pa` are differential values unless a field
  explicitly says absolute.
- Internal calculations convert absolute pressures and pressure drops to pascal.

## Gas Section

| Field | Meaning |
|---|---|
| `gas.composizione` | Mole fractions for the gas species. Values are normalized by the model. |
| `gas.portata_kgs` | Gas mass flow in kg/s before optional margin. |
| `gas.maggiorazione` | Multiplicative flow margin. |
| `gas.t_ingresso_C` | Gas inlet temperature in degC. |
| `gas.p_ingresso_bara` | Gas inlet absolute pressure in bara. |
| `gas.z` | User compressibility factor for ideal-base density calculation. |
| `gas.modello_gas` | `ideale`, `viriale`, or `realistico`. |
| `gas.gas_reale` | Backward-compatible boolean; used when `modello_gas` is absent. |
| `gas.miscelazione` | Transport-property mixing rule: `wilke` or `molare`. |
| `gas.irraggiamento` | Enables gas-radiation contribution. |
| `gas.shift` | `congelata`, `equilibrio`, or `parziale`. |

`realistico` currently means the implemented virial real-gas correction. It is
more realistic than the ideal option, but still limited for high-pressure syngas
and must be validated for final design use.

## Water And Steam Section

| Field | Meaning |
|---|---|
| `vapore.pressione_bara` | Steam drum absolute pressure in bara. |
| `vapore.t_alimento_C` | Feedwater temperature in degC. |
| `vapore.correlazione` | Pool-boiling correlation name. |
| `vapore.fouling_m2KW` | Shell-side fouling resistance. |
| `vapore.rugosita_um` | Water-side roughness in micrometre. |

## Circuit And Equipment Sections

- `circuito.downcomers` and `circuito.risers` describe connected piping.
- `drum` describes the steam drum geometry and internals used by the hydraulic
  and inventory summaries.
- `bypass` enables bypass heat-transfer, pressure-drop, valve and mixing checks.
- Tube, ferrule, baffle and shell dimensions drive both thermal calculations and
  the water-volume / metal-weight summary.

## Generated Output Contracts

Every normal run writes:

- `report.txt` and `report.html` for engineering review;
- `criticita.txt` for findings and warnings;
- `pds_comparison.txt` and `pds_comparison.csv` for mandatory client PDS checks;
- `inventory_summary.txt` and `inventory_summary.csv` for water volumes and
  estimated metal weights;
- detailed CSV/text files for cells, axial profiles, stresses, bypass valve,
  maldistribution and vibration.

## Compatibility Notes

- Existing files using only `gas.gas_reale` continue to work.
- New files should prefer `gas.modello_gas` for readability.
- The template keeps both fields during the transition.
